# 事務・アシスタント職の職業  
特徴：議事録、要約、指示書、社内説明資料などを作成し、組織の業務を円滑に進めるための文書作成・情報整理を担う。  
例：  
- 営業アシスタント  
- 秘書  
- 総務・管理部門  

-----------------------

# 主要タスクの内容

---

# 1 記事の要約（情報収集・インプット整理）  
事務・アシスタント職は、社内の意思決定や業務効率化のために必要な情報を整理し、関係者がすぐ理解できる形にまとめる役割を担います。

## 具体的な作業内容
- 社内外のニュース、業界情報、社内通達などを読み込み、関係部署に必要な部分だけを抽出して1〜2ページに要約する  
- 会議資料や議事録を読み解き、重要な決定事項・依頼事項・期限を整理したサマリーを作成する  
- 社内ルールや手続き変更の情報を確認し、要点をまとめて関係者に共有できる短い説明文に再構成する  
- 長文の報告書やプロジェクト資料を読み込み、上司が短時間で理解できる要点資料にまとめる  
- 情報を「結論 → 背景 → 必要なアクション」の構造に整理し、業務に直結するポイントだけを残す

---

# 2 指示書の作成（業務推進のための設計・指示）  
事務・アシスタント職は、社内の業務を円滑に進めるために、手順書・依頼書・社内向け説明文などを作成します。

## 具体的な作業内容
- 上司や部署からの依頼内容を整理し、作業指示書として「目的・手順・期限」を明確に記述する  
- 社内手続き（申請、承認、備品管理など）の流れを整理し、手順書として図や箇条書きで可視化する  
- 会議のアジェンダや進行表を作成し、関係者が準備すべき内容を明確にする  
- プロジェクトのタスクを整理し、WBSとしてスケジュールと担当者を一覧化する  
- 関係部署の役割を整理し、RACI（責任分担表）として明確化する  
- 外部パートナーや社内メンバーへの依頼事項を、メールや文書として「誰が・何を・いつまでに」形式で記述する  
- 社内ルールや運用変更をまとめ、周知文としてわかりやすく説明する

---

# 3 プレゼン資料作成（社内説明・報告）  
事務・アシスタント職は、社内会議や報告のために、わかりやすい資料を作成することが求められます。

## 具体的な作業内容
- 会議の目的・背景・現状・課題を整理し、論理的なストーリーライン（背景→現状→課題→対応策→次ステップ）を構築する  
- 上司や関係部署向けに、結論ファーストで1枚1メッセージのスライドを作成する  
- 業務データ（件数、進捗、コストなど）をグラフ化し、「So What（何が重要なのか）」をスライド上に明記する  
- 業務改善案や提案内容を、実行ステップ・必要リソース・影響範囲まで落とし込み、意思決定しやすい形に整理する  
- 社内文化や上司の好みに合わせて、表現・色使い・言葉遣いを調整する  
- プレゼン前に、想定質問と回答案（Q&A）を作成し、上司とレビューする  
- 発表に備えて、話す順番・強調ポイント・スライド切り替えのタイミングを練習する
