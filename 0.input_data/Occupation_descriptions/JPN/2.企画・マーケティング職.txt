# 企画・マーケティング職の職業  
特徴：市場や顧客の情報を整理し、企画案や施策指示書を作り、社内外向けのプレゼン資料を作るのが日常業務。  
例：  
- 事業企画  
- 商品企画  
- マーケティング担当  
- 広報・PR担当  

-----------------------
# 主要タスクの内容

# 1 記事の要約（情報収集・インプット整理）  
企画・マーケティング職は、意思決定に必要な市場情報・顧客動向・競合情報を短時間で整理し、企画や施策に活かせる形に再構成する必要があります。

## 具体的な作業内容
- 業界ニュース、調査レポート、SNSトレンド、顧客アンケートなどを読み込み、自社の企画に関連する部分だけを抽出して1〜2ページに要約する  
- 競合企業の新商品・キャンペーン・広告施策を調査し、強み・弱み・差別化ポイントを整理する  
- 市場規模、成長率、ターゲット属性などのデータをグラフ化しながら短いサマリーにまとめる  
- 長文の調査資料（100〜200ページ）を読み込み、企画会議で使えるレベルの要点資料に再構成する  
- 情報を「結論 → 根拠 → インサイト（示唆）」の構造に整理し、企画の方向性に直結するポイントだけを残す

---

# 2 指示書の作成（企画推進のための設計・指示）  
企画・マーケティング職は、社内外の関係者に「何を・いつまでに・どのように実行するか」を明確に伝えるための文書を作成します。

## 具体的な作業内容
- 新商品の企画意図やターゲットを整理し、企画概要書として文章と図で定義する  
- 現状の顧客行動や購買プロセスを整理し、課題点を可視化したカスタマージャーニーを作成する  
- 企画の目的とKPIを明確化し、施策の優先順位や実行ステップを箇条書きで整理する  
- 広告代理店や制作会社向けに、クリエイティブ指示書（トンマナ、メッセージ、素材要件）を作成する  
- プロジェクトのタスクを分解し、WBSとしてスケジュールと担当者を一覧化する  
- 関係部署（営業、開発、CSなど）の役割を整理し、RACIで責任分担を明確化する  
- 社内メンバーに依頼する作業を、手順書として「誰が・何を・いつまでに」形式で記述する

---

#3 プレゼン資料作成（社内外向け企画提案・報告）
企画・マーケティング職の成果物は、最終的にプレゼン資料として経営層・営業部門・外部パートナーに提示されるため、資料作成は極めて重要なタスクです。

## 具体的な作業内容
- 企画の背景・課題・インサイト・提案内容をもとに、論理的なストーリーライン（背景→課題→示唆→提案→効果）を構築する  
- 経営層向けに、結論ファーストで1枚1メッセージのスライドを作成する  
- 調査データや施策効果をグラフ化し、「So What（何が重要なのか）」をスライド上に明記する  
- 企画案を実行ステップ・必要リソース・予算・期待効果まで落とし込み、意思決定しやすい形に整理する  
- 社内文化や経営層の好みに合わせて、表現・色使い・言葉遣いを調整する  
- プレゼン前に、想定質問と回答案（Q&A）を作成し、上司や関係者とレビューする  
- 発表に備えて、話す順番・強調ポイント・スライド切り替えのタイミングを練習する
